WordChain은 계정 가입 없이 이용하는 끝말잇기 게임입니다. 게임 기록과 설정은 기본적으로 기기에 저장하고 Mildworks의 게임 서버로 보내지 않습니다. 광고는 앱에서 만 18세 이상을 선택한 경우에만 Google의 동의 처리 결과가 허용할 때 요청하며, 베타 알림은 만 18세 이상 이용자가 직접 켠 경우에만 구독합니다.

1. 처리하는 정보와 목적

앱에서 기기에 저장하는 정보

  • 연령대 및 앱 설정: 가장 어린 이용자의 연령대(만 14세 미만, 만 14~17세, 만 18세 이상, 미선택), 글씨 크기, 기본 시간 제한, 첫 차례 한방단어 규칙, 소리·진동, 베타 알림 선택, 날짜별 무료 힌트 사용량을 저장합니다. 생년월일은 묻지 않으며 이 설정은 앱 설정 파일에 보관합니다.
  • 진행 중인 게임: 판정된 단어와 뜻, 점수, 콤보, 생명, 남은 시간, 게임 모드와 AI 난이도, 저장 시각 및 2인 모드에서 입력한 플레이어 이름을 저장해 이어하기를 제공합니다. 새 게임을 시작하거나 게임이 끝나면 진행 정보를 지웁니다.
  • 종료 게임 기록: 점수, 사용 단어 수, 종료 시각, 주차, 시간 제한, 규칙 버전 및 게임 모드를 저장합니다. 최근 최대 100건과 모드별 최고 점수를 보관합니다.

이 정보는 앱의 게임 진행·기록 표시와 선택한 설정 적용에 사용됩니다. 단어 판정은 사전 데이터베이스와 함께 기기에서 처리합니다. 앱은 계정, 주소록, 사진, 마이크 또는 GPS 위치를 입력받지 않습니다. 2인 이름에는 실명이나 연락처 대신 별명을 사용해 주세요.

Google 광고 및 광고 선택

앱은 Google Mobile Ads SDK와 Google User Messaging Platform(UMP)을 사용합니다. 기기에서 만 18세 이상을 선택하고 UMP가 광고 요청을 허용하는 경우에만 광고 기능을 초기화합니다. 만 18세 미만이거나 연령을 선택하지 않은 경우 광고 SDK를 초기화하지 않습니다. 광고 콘텐츠 등급은 G로 설정되어 있습니다.

Google Mobile Ads SDK는 광고 제공, 광고 상호작용 측정 및 부정 사용 방지를 위해 IP 주소(일반 위치 추정에 이용될 수 있음), 앱 실행·탭·동영상 조회 등 상호작용, 앱·SDK 진단 정보, 광고 ID·앱 세트 ID 등 기기 식별자를 수집·공유할 수 있습니다. 광고 ID 수집 여부는 Android 및 SDK 설정에 따라 달라집니다. Google은 전송 중인 Mobile Ads 데이터를 TLS로 암호화한다고 안내합니다. 광고 개인 정보 선택 화면은 UMP가 필요하다고 판단하는 지역에서 앱 설정을 통해 다시 열 수 있습니다.

자세한 내용: Google Mobile Ads SDK 데이터 공개 안내 · Google UMP 개인정보 안내

베타 업데이트 알림

FCM 자동 초기화는 기본적으로 꺼져 있습니다. 만 18세 이상을 선택한 이용자가 앱 설정에서 알림을 켜면 앱이 FCM 토픽 구독을 요청합니다. FCM은 앱 설치별 Firebase 설치 ID(FID), 앱 버전, Firebase user agent 등을 알림 기능과 서비스 제공에 사용할 수 있습니다. 앱은 게임 단어나 점수, 연락처를 FCM으로 보내지 않습니다. Google은 Firebase user agent를 Firebase 서비스의 제공·유지·개선에 사용하며 사용자 또는 기기 식별자와 연결하지 않는다고 안내합니다.

알림을 끄면 앱은 토픽 구독 해제, FCM 등록 해제, FID 삭제를 차례로 요청하고 자동 초기화를 꺼 둡니다. 네트워크나 서비스 오류로 정리가 완료되지 않으면 알림 설정은 꺼진 상태로 유지하며 다음 앱 실행 때 다시 시도합니다. Google은 삭제 API 요청 뒤 해당 FID와 연결된 데이터를 활성 및 백업 시스템에서 최대 180일 이내 제거한다고 안내합니다. FID를 생성하는 Firebase 기능이 계속 필요하면 며칠 안에 별개의 새 FID가 생길 수 있습니다. 앱의 알림 설정 또는 Android 알림 권한에서 알림을 관리할 수 있으며, 알림을 사용하지 않아도 게임 이용에는 영향이 없습니다.

앱 업데이트와 개인정보처리방침 페이지

Google Play 인앱 업데이트 기능은 업데이트 가능 여부를 확인하고 업데이트를 안내하기 위해 Google Play와 통신합니다. 확인 과정에서 기기 메타데이터, 앱 버전, 설치된 모듈·에셋 팩 목록이 처리될 수 있습니다. 전송 중 암호화, 제3자 비공유, 보유·삭제 및 업데이트 설치를 미뤄도 조회가 중단되지 않는다는 안내는 Google Play 인앱 업데이트 데이터 안전 안내에서 확인할 수 있습니다.

이 개인정보처리방침 페이지는 GitHub Pages로 제공합니다. GitHub는 로그인 여부와 관계없이 방문자의 IP 주소를 보안 목적으로 기록·저장한다고 안내합니다. GitHub의 개인정보처리방침에 따라 방문·기기·요청 정보가 추가로 처리될 수 있으며 보유 기간은 처리 목적과 법적 의무에 따라 달라집니다. Mildworks는 이 페이지에 별도 문의 양식, 광고, 방문 분석 도구 또는 자체 쿠키를 설치하지 않습니다.

문의에 포함된 정보

이메일 또는 전화로 지원이나 개인정보 권리 행사를 요청하면 회신처와 문의 내용, 요청 처리에 필요한 최소한의 본인·대리인 확인 정보를 처리할 수 있습니다. 이메일을 기본 접수 경로로 사용하며 전화도 이용할 수 있습니다. 접수 후 2영업일 이내 접수 사실과 다음 단계를 확인하고, 접수일부터 10일 이내 처리를 목표로 합니다. 10일은 법정 처리기한이 아니며 실제 법정 기한을 별도로 따릅니다. 신분증 전체 사본이나 주민등록번호 등 불필요한 정보를 보내지 마세요.

2. 보유 기간과 삭제

  • 진행 중인 게임은 한 건만 보관하며, 게임 종료 또는 새 게임 시작 시 삭제합니다.
  • 종료 게임 기록은 최근 최대 100건으로 제한하고, 모드별 최고 점수는 이용자가 앱 데이터를 지우거나 앱을 삭제할 때까지 기기에 보관합니다.
  • 연령대와 앱 설정은 이용자가 바꾸거나 앱 데이터를 지울 때까지 기기에 보관합니다. 설정 파일과 FCM 설정은 Android 백업에서 제외하도록 구성되어 있습니다.
  • Android 백업이 허용된 경우 진행 데이터와 종료 기록 일부가 Google 백업으로 전송·복원될 수 있습니다. 특히 진행 중인 2인 이름이 포함될 수 있습니다. 앱은 Android 백업의 사본을 직접 열람하거나 삭제할 수 없습니다. 백업을 원하지 않으면 Android 설정에서 WordChain 백업을 관리하거나 끄세요. 백업에 관해서는 Android 자동 백업 안내를 확인할 수 있습니다.
  • 문의 원문과 첨부는 처리 완료 후 30일 이내 메일함·다운로드 폴더·휴지통에서 삭제합니다. 최소 처리 이력(무작위 요청 번호, 접수·완료일, 요청 분류, 권한 확인 방법, 처리 결과와 근거)은 완료일부터 1년 보관 후 삭제합니다. 법률상 별도 보존 의무가 확인되는 자료는 근거와 기간에 따라 분리 보관합니다.
  • GitHub Pages 방문 IP 정보, FCM 설치 ID, 광고·Google Play 서비스 정보는 각 제공자의 보유 정책을 따릅니다. GitHub Pages와 FCM의 안내된 처리 내용은 제1항과 제3항에 설명했습니다.

기기 안의 데이터는 Android 설정에서 WordChain 앱 데이터를 삭제하거나 앱을 삭제해 지울 수 있습니다. 이미 생성된 OS 백업 사본은 해당 기기에서 앱을 지워도 남거나 복원될 수 있습니다.

3. 외부 서비스 이용과 국외 처리

게임 기록은 Mildworks가 운영하는 게임 서버로 전송하지 않습니다. 아래 Google 서비스는 앱 기능을 제공하기 위해 이용 정보를 처리할 수 있고, GitHub Pages는 이 정책 페이지를 제공하며 방문자의 IP 주소를 보안 목적으로 처리할 수 있습니다. Google과 GitHub의 서비스는 각각의 전 세계 시설과 하위 처리자 운영 국가에서 정보를 처리할 수 있습니다.

Google Mobile Ads / UMP

  • 수령자와 연락처: 확인한 Google 광고 온라인 약관에 표시된 광고 서비스 계약 법인은 Google Asia Pacific Pte. Ltd.입니다. 주소는 Mapletree Business City II, 70 Pasir Panjang Road, #03-71, Singapore 117371입니다. Google 광고 서비스와 계열사·처리업체가 광고 데이터 처리에 참여할 수 있습니다. AdMob 계정의 계약 법인은 해당 계정의 Terms 첫 문단을 기준으로 하며, AdMob 계약 법인 안내에서 확인 방법을 볼 수 있습니다.
  • 정보·목적: 제1항의 IP 주소, 광고 ID·앱 세트 ID 등 식별자, 앱 상호작용 및 진단 정보를 광고 제공, 측정과 부정 사용 방지에 처리할 수 있습니다. UMP는 동의 정보 조회·저장과 필요한 동의 화면 제공에 사용합니다.
  • 국가·시기·방법: 대한민국을 포함해 Google 또는 광고 처리업체가 시설을 운영하는 국가(미국, 싱가포르 등)에서 처리될 수 있습니다. 만 18세 이상 선택 및 UMP 허용 후 광고 요청이 있을 때 인터넷을 통해 전송됩니다. 전송 보호 방식은 Google의 서비스 안내를 따릅니다.
  • 선택과 처리 근거: 광고 요청은 앱에서 만 18세 이상을 선택하고 UMP가 광고 요청을 허용한 경우에만 합니다. 지역과 Google 계정 설정에 따라 동의 화면이 표시되는 시점과 선택지는 달라질 수 있습니다. Google SDK가 직접 수집하는 광고 정보는 Google의 서비스 약관·개인정보처리방침 및 해당 지역의 동의 선택에 따라 처리됩니다.
  • 보유 기간·거부: 보유 기간은 Google의 광고·개인정보 정책과 이용자 광고 설정을 따르며 Mildworks가 개별 광고 데이터를 직접 보관·삭제하지 않습니다. UMP가 요구하는 동의 화면에서 선택을 바꿀 수 있고 Android 광고 ID 설정 또는 Google 광고 센터에서 광고 설정을 관리할 수 있습니다. 동의가 필요한데 동의하지 않으면 광고 요청이 제한될 수 있으며 게임은 계속 이용할 수 있습니다.

Firebase Cloud Messaging (FCM)

  • 수령자와 연락처: Google LLC 및 Google 계열사·Firebase 하위 처리자. Google APIs Terms의 기본 계약 주체는 Google LLC이며, 주소는 1600 Amphitheatre Parkway, Mountain View, CA 94043, United States입니다. 서비스 약관상 계열사가 서비스를 제공할 수 있습니다. Firebase 서비스 약관, Firebase 하위 처리자 목록, Firebase 개인정보 안내에서 최신 정보를 확인할 수 있습니다.
  • 정보·목적: FCM은 FID, 알림 전송 토큰, 앱 버전, Firebase user agent를 알림 전송·토픽 구독·서비스 제공에 처리할 수 있습니다. 게임 기록과 연락처는 Firebase로 보내지 않습니다. Firebase Android SDK 데이터 공개 안내도 확인할 수 있습니다.
  • 국가·시기·방법: 미국, 싱가포르 등 Google 또는 하위 처리자가 시설을 운영하는 국가에서 처리·보관될 수 있으며, Firebase 약관상 전 세계 시설이 포함될 수 있습니다. 이용자가 베타 알림을 켜거나 FCM SDK가 필요한 요청을 할 때 인터넷을 통해 전송됩니다. Firebase 서비스는 전송 중 HTTPS를 사용한다고 안내합니다.
  • 국외 처리: FCM은 이용자가 직접 켠 베타 알림을 제공합니다. Google 서비스는 서비스와 실제 연결 설정에 따라 정보를 해외에서 직접 수집하거나 Firebase의 처리위탁·보관 과정에서 처리할 수 있습니다. 국외 처리의 적용 근거는 서비스별 계약 관계와 실제 정보 흐름에 따라 확인해야 하므로 하나의 근거를 모든 Google 서비스에 일괄 적용하지 않습니다. FCM 알림은 앱에서 언제든 끌 수 있습니다. 관련 기준은 개인정보 보호법 제28조의8과 개인정보 포털의 국외이전 안내를 참고할 수 있습니다.
  • 보유 기간·거부: 알림을 끄면 앱이 FCM 토픽 해제, FCM 등록 해제 및 FID 삭제를 요청합니다. 오류로 완료되지 않으면 앱이 다음 실행 때 재시도합니다. Google은 FID 삭제 요청 후 연결 데이터를 활성·백업 시스템에서 최대 180일 이내 제거한다고 안내하며, Firebase 기능이 계속 FID를 필요로 하면 별개의 새 FID가 생길 수 있습니다. 베타 알림은 만 18세 이상 이용자가 앱 설정에서 켠 경우에만 구독을 요청하며 언제든 끌 수 있습니다. 알림을 사용하지 않아도 게임 이용에는 영향이 없습니다.
