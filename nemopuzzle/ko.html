운영자와 문의

네모나누기: 시카쿠 퍼즐은 Mildworks가 운영합니다. 개인정보 문의와 요청은 plainpocketapp@gmail.com 또는 010-4881-3717로 연락해 주세요.

기기에 저장하는 정보

퍼즐 진행, 완료한 판 ID, 실행 취소·다시 실행 기록, 설정, 앱 광고 간격 제한에 필요한 일부 카운터를 기기에 저장합니다. Mildworks 서버로 전송하지 않습니다. 계정이나 자체 분석·광고 프로필을 만들지 않습니다. 앱 저장공간을 지우거나 앱을 삭제하면 로컬 정보가 삭제됩니다. 사용자가 선택한 위치로 진행 백업 파일을 내보낼 수 있습니다. 백업에는 퍼즐 진행과 설정이 들어가며 광고 기록은 포함하지 않습니다. 백업 파일을 저장하는 클라우드나 다른 서비스는 해당 서비스의 약관을 따릅니다.

광고와 동의

이 앱에는 Google Mobile Ads SDK (Legacy) 25.5.0 및 Google User Messaging Platform(UMP) SDK 4.0.0이 포함됩니다. 광고 요청이 허용되면 Google SDK가 기기의 IP 주소, 앱 실행·탭 같은 앱 이용 상호작용, 진단 정보, 기기 또는 계정 식별자(Android 광고 ID, App Set ID, 해당하는 경우 기기 로그인 계정 식별자 포함)를 자동 수집하고 공유합니다. Google은 이 정보를 광고, 분석, 부정 이용 방지에 사용하며 전송 중 TLS로 암호화한다고 안내합니다. 이 SDK 요청으로 퍼즐 진행 정보가 Google에 전달되지는 않습니다.

UMP는 앱을 열 때마다 동의 상태를 확인하고, 해당 지역에 설정된 개인정보 안내를 표시하며 광고 요청 가능 여부를 결정합니다. 개인정보 선택 화면이 필요하면 설정에 진입점을 표시합니다. 실제 안내와 선택지는 광고 계정의 동의 설정과 이용자의 위치에 따라 달라집니다.

적격한 퍼즐 완료 전환에서만 전면광고를 최대 한 번 표시합니다. 풀이 중, 앱 실행·복귀 시, 다음 판 버튼 뒤, 힌트 사용 중에는 표시하지 않습니다. 광고를 사용할 수 없으면 해당 기회를 버립니다. 보상형·배너·앱 시작 광고, 구독, 인앱 결제는 제공하지 않습니다.

제3자

광고·동의 SDK는 Google이 제공합니다. Google 개인정보처리방침과 Google Mobile Ads SDK 데이터 공개 안내를 확인하세요.

선택과 요청

광고 개인화 설정을 끄거나 Android 설정에서 광고 ID를 재설정할 수 있습니다. 앱 설정에 개인정보 선택 항목이 표시되면 해당 항목을 이용하세요. 퍼즐 진행은 기기에만 저장되므로 Mildworks가 원격으로 조회하거나 삭제할 수 없습니다. 앱 저장공간을 지우거나 앱을 삭제해 로컬 정보를 삭제할 수 있습니다. SDK를 통해 Google에 직접 전달된 정보는 Google의 정책과 도구를 따릅니다.
